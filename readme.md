## Akin Wallet centralized digital wallet for identity, financial cards, credentials, and personal information.

## Features

- **Identity Management** — Store and manage your personal identity information
- **Financial Cards** — Securely store credit/debit cards
- **Credentials** — Keep your login credentials and access tokens organized
- **Personal Information** — Manage addresses, contacts, and personal details
- **Secure Storage** — Encrypted local storage for all sensitive data
